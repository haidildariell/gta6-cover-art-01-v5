# Fonts shipped with Golden Hour Cover Lab

Two display faces, both under the SIL Open Font License version 1.1,
which allows redistribution with the app, including in modified form,
as long as the fonts stay under this same licence and are not sold
on their own.

- Anton Regular (Anton-Regular.ttf) — a condensed display face used
  for the big cover titles. Designed by Vernon Adams, The Anton
  Project Authors. Copyright 2020 The Anton Project Authors.
- Pacifico Regular (Pacifico-Regular.ttf) — a casual script face
  used for the neon script subtitle. Designed by Vernon Adams,
  The Pacifico Project Authors. Copyright 2018 The Pacifico
  Project Authors.

Both files were downloaded as binaries from the Google Fonts
repository (github.com/google/fonts), where each font is published
under the SIL Open Font License 1.1. The full licence text of
version 1.1 is the standard SIL Open Font License text; a copy
ships with the font's upstream repository. No other font is used:
every other letterform in the app falls back to the system sans
face, and no game or brand font is included anywhere.
